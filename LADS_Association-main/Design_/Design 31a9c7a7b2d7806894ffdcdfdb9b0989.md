# 6. Important UX Notes

### Must Have

- Clear CTA buttons
- Fast navigation
- Premium dashboard feel
- Clean spacing
- No visual overload
- Strong section hierarchy

### Avoid

- Too many colors
- Heavy animations
- Complex layouts
- Old-fashioned association style
